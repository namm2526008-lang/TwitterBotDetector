# TwitterBotDetector
Tool to check for bot account on Twitter

## Introduction

Day la repository phuc vu cho muc dich hoc tap, khong chua san pham nghien cuu. 

## Goal

Phan biet giua tai khoan that va tai khoan bot tren mang xa hoi Twitter

## Method

Thanh lap mot he thong cac tieu chi danh gia va su dung mot dataset gom nhieu tai khoan. Tu do danh gia cac tai khoan theo tieu chi de xac nhan bot va dua ra du doan.
